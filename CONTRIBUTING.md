# Contributing

Thanks for improving Deal Inspector.

## Ground rules

- Every score stays evidence-backed (name, date, document, or observed behaviour).
- Sentiment alone is never enough for a high MEDDPICC score.
- Prefer small PRs: one silent killer, one rubric tweak, or docs.

## How to contribute

1. Fork and branch from `master`.
2. Edit `SKILL.md`, `docs/`, `examples/`, or installers.
3. Open a Pull Request with a short rationale and, for skill changes, a before/after verdict example.

## Issues

Use `.github/ISSUE_TEMPLATE/` for bugs and feature requests.
