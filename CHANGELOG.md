# Changelog

## 2.0.0 — Unreleased draft (2026-10-14)

This describes the v2 working change set, not a release announcement or a claim that validation gates have passed. Check published evaluation and compatibility results before relying on a supported-platform claim.

### Changed

- Reworked qualification around SMB buying evidence, fit, pursuit, and grounded forecast posture.
- Replaced numeric forecast thresholds and unsupported timing rules with explicit uncertainty and buying-process reasoning.
- Defined concise inspection, previous-review updates, and compact pipeline review.
- Added buyer adoption risk, pilot success criteria, price-objection diagnosis, and observable next-action outcomes.
- Clarified portable copy-paste use, Claude Code installation, privacy, and evaluation.
- Updated contribution and issue templates for safe reproductions and honest test reporting.

### Compatibility

Recommendations and output differ from v1. Do not compare old qualification totals with v2 judgments or interpret them as win probabilities. Legacy-file cleanup must be explicit; reinstalling must preserve unrelated skills.
